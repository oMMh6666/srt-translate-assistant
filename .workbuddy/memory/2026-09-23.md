  `context.py`（上下文）、`runner.py`（线程 + 注册表）、`events.py`（广播订阅 + 环形缓冲）、`db.py`（sqlite 串行）。

### SSE 协议（定稿）

具名事件 `log / batch / status / export / end`，单调 seq，环形缓冲 200 条，
断线重连用 `Last-Event-ID` 补发，15s 心跳注释帧，首帧 `retry: 3000`；`end` 广播给全部订阅者。
界面另有 2.5s 轮询兜底，SSE 只是加速器。

### 两个真 bug（都不是本次重构引入）

1. **sqlite 在 Windows 上被降级成只读**：「每个操作新开连接」在多线程反复开关同一库时 `-shm` 竞争，
   报 `attempt to write a readonly database`，任务卡 PENDING。压测：WAL 3 次报错 / DELETE 3 次 locked /
   全局串行 0 次。修法：`core/db.py` 全局 `RLock` + `busy_timeout` + 用完即关，jobs/keys 全走它。
2. **删除任务偶发 WinError 32**：刚写完的 db 被杀软/索引器短暂占用。`trash_job` 内加 6 拍重试。
